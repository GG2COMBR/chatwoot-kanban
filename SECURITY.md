# Política de Segurança

A segurança do módulo **Chatwoot Kanban** e dos dados dos usuários é prioridade fundamental.

## Versões Suportadas

Atualmente fornecemos atualizações de segurança para as seguintes versões:

| Versão | Suporte a Correções de Segurança |
| :--- | :--- |
| 1.0.x | :white_check_mark: Suportado |
| < 1.0.0 | :x: Não suportado |

## Como Reportar Vulnerabilidades

Caso você encontre uma potencial vulnerabilidade de segurança neste projeto:

1. **NÃO crie uma issue pública no GitHub.**
2. Envie um e-mail com os detalhes para: **[gihovani@gg2.com.br](mailto:gihovani@gg2.com.br)**.
3. Inclua, se possível:
   - Descrição detalhada da vulnerabilidade;
   - Passos reproduzíveis ou Prova de Conceito (PoC);
   - Versão do Chatwoot e do pacote utilizada;
   - Impacto estimado.

### Nosso Compromisso

- Responderemos ao seu contato em até 48 horas úteis.
- Trabalharemos em uma correção prioritária antes de qualquer divulgação pública.
- Daremos o devido crédito de agradecimento caso solicitado.
